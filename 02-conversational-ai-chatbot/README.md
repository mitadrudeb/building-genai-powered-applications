# Conversational AI Chatbot: Open-Source vs Frontier Models

Work in progress. This project is being rebuilt as three Jupyter notebooks:

1. `01_open_source_chatbot.ipynb`: a chatbot with a local open-source model (Qwen3.5)
2. `02_frontier_chatbot.ipynb`: the same chatbot with the OpenAI API
3. `03_final_chatbot_app.ipynb`: one app that can use both, and a comparison
